Steps to run the IIIT Allahabad Cultural Council website locally

1. Open a terminal (PowerShell or Command Prompt) and navigate to the project directory:
   cd "C:\Users\Asus\Desktop\council web"

2. Make sure MongoDB is running locally (or configured in .env.local):
   # To verify MongoDB status in PowerShell:
   Get-Service *mongo*
   # Or ensure your MongoDB connection string in .env.local is reachable:
   MONGODB_URI=mongodb://127.0.0.1:27017/iiita_cultural_council

3. Seed initial database data (societies, fests, events):
   npm run seed

4. Start the development server:
   npm run dev

5. Open the website in your browser:
   http://localhost:3000

6. To stop the development server:
   Press Ctrl+C in the terminal.

Optional production build and run:
   npm run build
   npm run start
